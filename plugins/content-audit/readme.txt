ویجتی برای داشبورد که نوشته‌های ناقص را نشان می‌دهد.

== Description ==
هر نوشته‌ای که یکی از این سه مورد را کم داشته باشد، در داشبورد فهرست می‌شود:

* توضیح (description)
* برچسب (tags)
* تصویر شاخص (heroImage)

هر ردیف به صفحهٔ ویرایش همان نوشته لینک می‌شود، پس رفع نقص یک کلیک فاصله دارد.

== Installation ==
1. پوشهٔ افزونه را در plugins قرار دهید.
2. از صفحهٔ افزونه‌ها فعالش کنید.
3. داشبورد را باز کنید؛ ویجت «بازبینی محتوا» اضافه شده است.

== Frequently Asked Questions ==
= آیا پیش‌نویس‌ها هم بررسی می‌شوند؟ =
بله، به‌صورت پیش‌فرض. از تنظیمات افزونه می‌توانید خاموشش کنید.

= آیا افزونه به فایل‌ها دسترسی دارد؟ =
نه. داده را از context فیلتر می‌گیرد و فقط HTML امن برمی‌گرداند.
