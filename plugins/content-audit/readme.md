# بازبینی محتوا

نمونهٔ افزونه‌ای که فقط سمت پنل کار می‌کند و یک ویجت به داشبورد اضافه می‌کند.

| | |
| --- | --- |
| نسخه | ۱٫۰٫۰ |
| نیازمند پنل | ۲٫۰٫۰ |
| مجوز | MIT |
| قلاب‌ها | `cms.dashboard.widgets` |

## چه می‌کند؟

نوشته‌هایی را که یکی از این موارد را کم دارند فهرست می‌کند:

- توضیح (description)
- برچسب (tags)
- تصویر شاخص (heroImage)

هر مورد به صفحهٔ ویرایش همان نوشته لینک می‌شود.

## تنظیمات

| کلید | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `includeDrafts` | سوییچ | روشن | پیش‌نویس‌ها هم بررسی شوند. |
| `maxItems` | متن | `5` | بیشترین تعداد نمایش (۱ تا ۱۰). |

## چرا این نمونه مهم است؟

این افزونه نشان می‌دهد یک افزونهٔ سمت پنل:

1. به فایل‌ها دسترسی ندارد — داده را از `context` فیلتر می‌گیرد.
2. خروجی HTML را خودش می‌سازد و باید آن را ایمن کند (`escapeHtml`).
3. می‌تواند تنظیمات داشته باشد؛ پنل فرمش را خودکار می‌سازد.
