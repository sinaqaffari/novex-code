کنونیکال، Open Graph، Twitter Card و دادهٔ ساختاریافتهٔ JSON-LD برای صفحه‌های عمومی.

== Description ==
این افزونه سر همهٔ صفحه‌های عمومی — خانه، مجله، نوشته‌ها و فروشگاه — را کامل می‌کند:

* تگ کنونیکال برای جلوگیری از محتوای تکراری
* تگ‌های Open Graph با عنوان، توضیح، تصویر و نوع صفحه
* تگ‌های Twitter Card با پشتیبانی از تصویر شاخص
* دادهٔ ساختاریافته: BlogPosting برای نوشته‌ها و WebSite برای بقیهٔ صفحه‌ها

همهٔ مقادیر پیش از قرارگرفتن در HTML کدگذاری می‌شوند و JSON-LD در برابر
بسته‌شدن ناخواستهٔ تگ محافظت می‌شود.

== Installation ==
1. پوشهٔ افزونه را در plugins قرار دهید.
2. از صفحهٔ افزونه‌ها آن را فعال کنید.
3. در تنظیمات، نام کاربری شبکهٔ اجتماعی را وارد کنید.
