افزونهٔ بومی TypeScript برای تکمیل فرادادهٔ صفحات عمومی؛ افزونهٔ PHP وردپرس نیست.

== Description ==
پوستهٔ نووکس‌کد عنوان، توضیح و فرادادهٔ پایهٔ Open Graph را تولید می‌کند. پس از فعال‌سازی، این افزونه موارد زیر را اضافه می‌کند:

* نشانی canonical
* نام سایت در Open Graph
* Twitter Card و شناسهٔ اختیاری حساب
* دادهٔ ساختاریافته: BlogPosting برای نوشته‌ها و WebSite برای صفحه‌های دیگر

صفحه‌هایی که noindex هستند از خروجی افزونه مستثنا می‌شوند. همهٔ مقادیر پیش از
قرارگرفتن در HTML کدگذاری می‌شوند و JSON-LD در برابر بسته‌شدن ناخواستهٔ تگ محافظت می‌شود.

== Installation ==
1. پوشهٔ افزونه را در plugins قرار دهید.
2. از صفحهٔ افزونه‌ها آن را فعال کنید.
3. در تنظیمات، نام کاربری شبکهٔ اجتماعی را وارد کنید.
