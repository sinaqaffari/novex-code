# سئوی صفحات عمومی

افزونهٔ مرجع برای قرارداد افزونه‌های پنل نووکس‌کد.

| | |
| --- | --- |
| نسخه | ۱٫۰٫۰ |
| نیازمند پنل | ۲٫۰٫۰ |
| مجوز | MIT |
| قلاب‌ها | `site.head` |

## چه می‌کند؟

به سر همهٔ صفحه‌های عمومی این‌ها را اضافه می‌کند:

- `<link rel="canonical">`
- تگ‌های Open Graph (`og:title`، `og:description`، `og:image`، `og:type`، …)
- تگ‌های Twitter Card
- دادهٔ ساختاریافتهٔ JSON-LD — `BlogPosting` برای نوشته‌ها و `WebSite` برای بقیه

## تنظیمات

| کلید | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `twitterHandle` | متن | خالی | در `twitter:site` استفاده می‌شود. |
| `enableJsonLd` | سوییچ | روشن | خروجی JSON-LD را خاموش/روشن می‌کند. |

تنظیمات از `/cms/plugins` ذخیره می‌شوند و در `data/plugins.json` نگه‌داری می‌شوند.

## ساختار

```text
seo-meta/
├─ plugin.json     هدر افزونه (نام، نسخه، قلاب‌ها، تنظیمات)
├─ index.ts        نقطهٔ ورود — فقط register(api)
└─ readme.md       همین فایل
```

## نکتهٔ امنیتی

همهٔ مقادیر پیش از قرارگرفتن در HTML با `escapeAttribute` کدگذاری می‌شوند و JSON-LD با
`escapeJsonLd` از بسته‌شدن ناخواستهٔ تگ محافظت می‌شود.
