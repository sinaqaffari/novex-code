افزونهٔ بومی TypeScript برای نووکس‌کد؛ افزونهٔ PHP وردپرس نیست.

== Description ==

این افزونه صفحهٔ پیکربندی کلید محیطی، شمارهٔ فرستنده و نام قالب تأیید را دارد و توابع سروری ارسال SMS و Verify Lookup را ارائه می‌کند.

فعال‌سازی یا ذخیرهٔ تنظیمات به‌تنهایی پیامکی ارسال نمی‌کند. در نسخهٔ فعلی، گردش‌کارهای خرید، ورود یا تأیید حساب به توابع این افزونه متصل نیستند. ارسال واقعی از سرویس بیرونی در این مخزن آزمایش نشده است.

== Configuration ==

1. در secret manager محیط اجرا، `NOVEX_PLUGIN_KAVEH_NEG_SMS_API_KEY` را تنظیم کنید. مقدار کلید در CMS یا فایل JSON ذخیره نمی‌شود.
2. شمارهٔ فرستندهٔ تأییدشدهٔ حساب را ثبت کنید.
3. برای Verify Lookup، نام قالبی را وارد کنید که در پنل سرویس ساخته‌اید؛ این فیلد متن پیام نیست.

== Frequently Asked Questions ==

= آیا فعال‌سازی افزونه برای مشتری پیامک می‌فرستد؟ =

خیر. هیچ پیام خودکاری با فعال‌سازی ارسال نمی‌شود و گردش‌کار خرید به این افزونه وصل نیست.

= آیا کلید محرمانه در پنل ذخیره می‌شود؟ =

خیر. پنل فقط وجود secret را نمایش می‌دهد؛ مقدار آن از محیط اجرا خوانده می‌شود.
