ارسال پیامک تاییدیه و اعلان از طریق پنل پیامک کاوه‌نگار (Kaveh Negar).

== Description ==

این افزونه امکان ارسال پیامک و کد تایید (OTP) از طریق سرویس کاوه‌نگار را به فروشگاه نووکس‌کد اضافه می‌کند.

ویژگی‌ها:

* ارسال پیامک عادی به مشتریان.
* ارسال کد تایید (OTP) برای تایید شماره تماس مشتریان.
* صفحهٔ تنظیمات در پنل مدیریت برای مدیریت API Key، شماره فرستنده و قالب پیامک.

== Installation ==

1. پوشهٔ افزونه را در `plugins/kaveh-neg-sms/` قرار دهید.
2. از صفحهٔ افزونه‌ها در پنل مدیریت، افزونه «پیامک کاوه‌نگار» را فعال کنید.
3. در صفحهٔ تنظیمات افزونه، کلید API و شماره فرستنده کاوه‌نگار را وارد کنید.
4. قالب پیش‌فرض پیامک را تعریف کنید (مثلاً «کد تایید شما: {code}»).

== Frequently Asked Questions ==

= آیا این افزونه به پایگاه‌داده دسترسی مستقیم دارد؟ =

نه. داده را از API کاوه‌نگار می‌گیرد و فقط پاسخ را برمی‌گرداند.

= آیا برای تست نیاز به کلید API واقعی است؟ =

بله. برای ارسال واقعی پیامک، کلید API معتبر از کاوه‌نگار نیاز است.
