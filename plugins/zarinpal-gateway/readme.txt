اتصال فروشگاه نووکس‌کد به درگاه پرداخت زرین‌پال برای خرید محصولات آنلاین.

== Description ==

این افزونه امکان اتصال فروشگاه نووکس‌کد به درگاه پرداخت زرین‌پال را فراهم می‌کند تا مشتریان بتوانند محصولات را با کارت 멤버ی پرداخت کنند.

ویژگی‌ها:

* اتصال به درگاه زرین‌پال (حالت عملی و آزمایشی).
* درخواست پرداخت و دریافت آدرس درگاه برایRedirect کاربر.
* تایید پرداخت پس از بازگشت از بانک و به‌روزرسانی وضعیت سفارش.
* صفحهٔ تنظیمات در پنل مدیریت برای مدیریت Merchant ID و حالت Sandbox.

== Installation ==

1. پوشهٔ افزونه را در `plugins/zarinpal-gateway/` قرار دهید.
2. از صفحهٔ افزونه‌ها در پنل مدیریت، افزونه «درگاه پرداخت زرین‌پال» را فعال کنید.
3. در صفحهٔ تنظیمات افزونه، Merchant ID خود را وارد کنید و حالت Sandbox را فعال/غیرفعال کنید.
4. در سرویس زرین‌پال، آدرس callback سایت خود را ثبت کنید (مثلاً `https://domen-shoMa.com/shop/payment/callback`).

== Frequently Asked Questions ==

= آیا این افزونه به پایگاه‌داده دسترسی مستقیم دارد؟ =

نه. داده را از API می‌گیرد و فقط HTML امن برمی‌گرداند.

= آیا درگاه آزمایشی پشتیبانی می‌شود؟ =

بله. با فعال کردن تنظیمه «حالت آزمایشی (Sandbox)» به محیط آزمایشی زرین‌پال وصل می‌شود.

= چگونه وضعیت سفارش به «پرداخت‌شده» تغییر می‌کند؟ =

پس از بازگشت کاربر از بانک، افزونه پرداخت را تایید می‌کند و وضعیت سفارش را به `paid` تغییر می‌دهد.
