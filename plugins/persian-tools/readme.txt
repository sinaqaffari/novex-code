افزونهٔ بومی TypeScript برای داشبورد نووکس‌کد؛ افزونهٔ PHP وردپرس نیست.

== Description ==

این افزونه یک ویجت تاریخ و زمان امروز را در داشبورد پنل اضافه می‌کند. تاریخ با تقویم جلالی و منطقهٔ زمانی Asia/Tehran نمایش داده می‌شود.

تنظیمات فرمت تاریخ، اعداد فارسی و روز هفته فقط روی همین ویجت اثر دارند؛ این افزونه اعداد و تاریخ سایر صفحه‌های سایت را تغییر نمی‌دهد. تنظیمات عمومی سایت در بخش تنظیمات CMS قرار دارند.

== Installation ==

1. از صفحهٔ افزونه‌ها، «ابزارهای فارسی» را فعال کنید.
2. داشبورد را باز کنید تا ویجت تاریخ را ببینید.
3. از دکمهٔ «پنل افزونه» فرمت و شیوهٔ نمایش ویجت را تغییر دهید.

== Frequently Asked Questions ==

خیر. فرمت‌کننده‌ها به‌طور صریح از Asia/Tehran استفاده می‌کنند.
