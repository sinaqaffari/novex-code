ابزارهای فارسی برای پنل مدیریت نووکس‌کد — تقویم جلالی، اعداد فارسی و تنظیمات نمایش تاریخ.

== Description ==

این افزونه تاریخ‌ها را بر اساس تقویم شمسی (جلالی) نمایش می‌دهد و اعداد انگلیسی را به اعداد فارسی تبدیل می‌کند.

ویژگی‌ها:

* ویجت داشبورد با تاریخ و زمان امروز در تقویم جلالی (منطقهٔ زمانی تهران).
* صفحهٔ تنظیمات برای انتخاب فرمت تاریخ (کوتاه / متوسط / طولانی).
* فعال/غیرفعال کردن اعداد فارسی در کل سایت.
* نمایش یا پنهان کردن روز هفته در تاریخ.

== Installation ==

1. پوشهٔ افزونه را در `plugins/persian-tools/` قرار دهید.
2. از صفحهٔ افزونه‌ها در پنل مدیریت، افزونه «ابزارهای فارسی» را فعال کنید.
3. داشبورد را باز کنید؛ ویجت «تاریخ امروز (جلالی)» اضافه شده است.
4. در صفحهٔ افزونه‌ها روی «تنظیمات» کلیک کنید تا فرمت تاریخ را انتخاب کنید.

== Frequently Asked Questions ==

= آیا این افزونه به فایل‌های سایت دسترسی دارد؟ =

نه. داده را از API می‌گیرد و فقط HTML امن برمی‌گرداند.

= آیا تقویم به صورت جلالی است؟ =

بله. از `Intl.DateTimeFormat` با لوکال `fa-IR-u-ca-persian` استفاده می‌شود.

= آیا اعداد به فارسی تبدیل می‌شوند؟ =

بله، اگر تنظیمه «استفاده از اعداد فارسی در کل سایت» فعال باشد.
