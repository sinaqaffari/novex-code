# Bundled site kits

The template dialog offers one versioned Persian business starter containing three draft pages: home, services, and contact. Preview each page and choose a unique ASCII slug prefix before confirming installation. It uses existing native component types and one bundled sample image; replace that image with your own before publication. The sample content, pricing and links must be reviewed and replaced before publication.

The server validates the bundled kit, component declarations and documents. It accepts only explicitly declared bundled media references and checks each file exists before writing; it rejects kits whose asset dependencies cannot be resolved and refuses to overwrite any existing page. All pages are checked and written in one queued file-store write; the implementation does not claim cross-process locking. Installation creates drafts and does not publish. This is a single-site installation and does not create a new tenant. Assets are reused from the existing local media library; no remote downloads or package-asset copying occur. Shared header/footer ownership, package uploads, update merging and package provenance are not implemented.

Kit pages declare button-to-page links by target suffix. Installation validates every target and button, then resolves links to `/pages/<prefix>-<suffix>` before allocating fresh node IDs. The linked destinations remain drafts and return 404 publicly until each is explicitly published; preview uses placeholder links. Existing unrelated links and pages are not rewritten.
